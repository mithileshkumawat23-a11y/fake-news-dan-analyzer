Fake News DNA Analyzer

About the Project

Fake News DNA Analyzer is an AI/ML-based web application designed to analyze news text and help users assess whether it may be fake or real.

Key Features

- AI/ML-based news classification
- Text preprocessing and analysis
- Model-based prediction
- Explainability support
- Evidence-related analysis

Technologies Used

- Python
- Machine Learning
- Pandas and NumPy
- HTML, CSS, and JavaScript
- Java and Spring Boot

Project Structure

- "ai-service/" — Python AI/ML service
- "Backend/" — Java Spring Boot backend
- Frontend files — Web interface
